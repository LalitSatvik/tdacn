# TDACN Dashboard

Frontend for [Temporal Drift in Accounting Concept Networks](../README.md)
— five pages (Overview, Explorer, Segmentation, Findings, Architecture)
built with Next.js (App Router), TypeScript, Tailwind CSS, and D3.js.

## Data

This app reads static JSON from `public/data/`, generated by
`../scripts/export_dashboard_data.py` from the pipeline's parquet/pickle
outputs. There is no backend/API — regenerate the data by re-running that
script (from the repo root, in the `lalitenv` conda env) after any
pipeline change, then commit the updated JSON:

```bash
conda activate lalitenv
python ../scripts/export_dashboard_data.py
```

## Develop

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # production build (fully static — no server needed)
```

## Structure

- `app/` — one route per page (`page.tsx`, `explorer/`, `segmentation/`,
  `findings/`, `architecture/`)
- `components/graph/` — the D3 + `<canvas>` network graph (`network-graph.tsx`)
  and the decorative hero variant (`hero-graph.tsx`)
- `components/charts/` — reusable D3 SVG bar/scatter/sparkline components
- `components/explorer/` — Explorer-page filter rail and concept detail panel
- `components/ui/` — shadcn-style primitives, including the supplied
  `liquid-glass-button.tsx` (`LiquidButton` / `MetalButton`)
- `lib/data.ts`, `lib/types.ts` — data loading + the JSON shapes written
  by the export script
